Running in under two minutes

One container, pointed at the NATS server you already have. JetStream and the monitoring port (-m 8222) must be enabled.

bash
docker run -d -p 3000:3000 \
  -e NATS_URL=nats://your-nats-host:4222 \
  -e JWT_SECRET="$(openssl rand -hex 32)" \
  -v jetyard-data:/data \
  ghcr.io/imadmansour85/jetyard:latest
1. Run the containerAdd NATS_USER/NATS_PASSWORD or NATS_TOKEN if your server needs them.
2. Open localhost:3000Create the first admin account, then add your team's logins.
3. Optional: accountsSet OPERATOR_NKEY_SEED to issue NATS accounts and users from the UI.
